# Machine Learning Model

## Goal

Predict post-earnings stock movement.

---

### Inputs

- Historical earnings
- Historical price reactions
- Technical indicators
- Momentum
- Volatility
- Volume
- Analyst revisions
- Sector strength
- Options implied move (future)

---

### Outputs

- Bullish / Bearish
- Probability
- Confidence
- Expected Move
- EarningsEdge Score

---

### Version 1 Models

- Logistic Regression
- Random Forest

---

### Future Models

- XGBoost
- LightGBM
- Neural Networks

---

### Evaluation

- Accuracy
- Precision
- Recall
- F1 Score
- ROC-AUC
